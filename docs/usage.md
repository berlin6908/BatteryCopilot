# 使用指南

先按 [README](../README.md#快速开始)启动数据库、导入数据并配置模型。
工作台包含制造履历、结构与记录、工艺证据、变更复核四个页面。

## 制造履历与检验复核

1. 在「制造履历」选择测试关联电芯。
2. 展开工序，查看该对象的参数及明确前驱。每个工序对应同一行的产物对象。
3. 在「循环测试记录」翻页查看充放电容量，点击行号打开原始数据。
4. 在「复核任务」输入问题，点击「生成制造复核报告」。
5. 检查报告中的结论、来源和待补充资料，填写复核人、意见与复核结论。
6. 导出 Markdown 报告。报告包含来源快照，刷新后可从「已保存报告」继续查看。

示例问题：

> 追溯当前电芯的明确前驱和制造工序，核对 Cycle 1 的充放电容量，
> 列出缺失的工艺参数与测试条件。每条结论给出来源，并说明现在能否作质量判定。

默认样本 `FormatedCell1 · 101_tizue-ki-230306-tizue-0400-059_-STATS-.txt` 的
Cycle 1 放电容量为 **0.438290374336 Ah**，可在原文件第 11 行核对。
其明确履历为 Stacking Protocol → DryCell、Filling Protocol → FilledCell1、
Formation Protocol → FormatedCell1。DryCell 是当前记录的追溯终点，不代表制造从此开始。

复核意见保存后保留在该报告中；需要重新分析时生成新报告。
缺少测试程序、电流、温度条件或验收标准时，报告会列出资料缺口。

## 结构与记录

在「结构与记录」选择电池包和对象，查看部件、连接件及拆解操作之间的关系。
点击图节点或来源按钮可打开原始 CSV 行；操作序列按数据中的记录顺序展示。
右侧助手可回答连接关系、对象数量和记录查询问题，并提供可点击的引用。

![部件关系与记录查询](images/workbench.png)

## 工艺证据

在「工艺证据」输入中文、英文或德文问题，或使用页码按钮浏览指南。
点击检索结果会打开原页图像、高亮区域及对应原文。

可尝试「产线布局中的缓冲站和返工区域」。
引用绑定 PDF 文件版本、页码和区域；重新分块后仍可读取同版本 PDF 中的原区域。
指南中的通用工艺要求应结合具体对象资料使用，不能直接视为某型号的工艺参数。

## 变更复核

1. 进入「变更复核」→「新建申请」，填写对象、变更原因、规格和相关资料。
2. 保存申请，点击「分析当前资料」，查看工具规格适配、指导书同步和关联对象检查。
3. 若缺资料，补充工具卡或指导书后重新分析；若存在冲突，修改对应规格和版次。
4. 查看每项证据，填写复核人及意见，逐项确认后完成变更单并导出报告。

正常、缺资料和冲突示例使用明确标记的模拟输入。
修改资料会生成新的输入版本，旧报告和复核记录保留在历史中。
模型调用失败时申请仍保留，可点击「重试分析」。尚未完成的报告也可导出，并显示实际状态。
变更单完成表示资料检查与人工复核已完成。
