## 已知质量边界

后续指南修复（`f739792`）将独立解析后的8道开发检索探针从6/8提高到8/8。
新增4种意图的中英德表达共12问，页命中10/12、原文区域命中9/12，仍有明确漏检。
25个因重新分块而从索引消失的原区域引用，25/25可直接从同版本PDF读取。
本轮后端34项检查通过，Ruff通过。方法、延迟与分步结果见[指南验证](guide-validation.md)。
本轮 Edge 实际流程检查了中文/德文检索、PDF 区域引用、报告历史恢复、演示复核与来源导出，
无页面或控制台错误。录制脚本使用真实画布滚动，避免只移动 Flutter 的无障碍节点。

原300题的指南部分依赖703元素解析快照。干净检出的新解析不能直接复现旧指南成绩，
执行器现会检查解析指纹并停止不匹配的评测；原题库和成绩没有被改写。
详见[历史评测重现条件](benchmark-300.md#历史解析快照要求)。

制造功能基于公开实验室记录，没有工业用户验收。最终制造重放题目已被查看，
固定查询与Agent均通过24/24的字段及预设引用检查，不代表未见批次泛化或完整工业正确率。

## 运行检查

先完成 README 的安装、数据导入和前端构建，再执行：

```powershell
$env:PYTHONUTF8 = '1'
uv run pytest -q
uv run ruff check backend
# 以下脚本需要Playwright Node包与本机Edge；请对独立测试数据库运行。
$env:BASE_URL = 'http://127.0.0.1:8000'
$env:LIVE_AGENT = '1'
node scripts/smoke-browser.cjs
$env:TEST_REVIEW = '1'
node scripts/smoke-manufacturing.cjs
```

原始模型轨迹、截图、环境和测试生成的报告保留在本机被忽略的目录。
公开仓库保留源码、锁文件、数据署名、题库、结果摘要和来源抽查。
当前构建与检查命令见[开发文档](development.md)，功能操作见[使用指南](usage.md)。
