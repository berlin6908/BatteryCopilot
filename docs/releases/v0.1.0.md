# v0.1.0 — 制造资料复核与稳定引用

从一个电芯对象出发，追溯明确制造前驱、核对工序参数和循环原始行，生成有来源的资料复核报告。
报告可保存、人工复核、刷新恢复并导出来源快照。基于公开 KIproBatt 实验室制造记录。

- 制造履历、循环编号定位和参数对象归属；单 Agent 调用领域工具。
- PDF 引用绑定文件版本、页码和矩形，分块变化后仍可解析旧区域。
- 补回布局图原生文字，用多语言重排改善中、德文工艺指南检索。
- 包含 KIT 结构关系浏览，以及模拟变更的补资料、修订、复核与导出流程。
- 发布三分钟字幕演示，安装说明、题库、分步评测和失败审查均在仓库中。

验证：后端 34 项检查通过，Ruff 通过；独立检出已完成安装、重新导入和 Flutter 构建。
本轮浏览器核对图浏览、CSV、中文/德文检索与 PDF 区域来源，演示核对报告历史、复核和导出。
指南 8 道原开发探针页命中 8/8；4 个新增意图的三语表达共 12 问，页命中 10/12、
区域命中 9/12。同批制造修复重放中，固定查询和 Agent 的字段及预设引用检查均为24/24；
这些结果是开发验证，不是工业用户验收或未见数据泛化证明。

尚有局限：指南重排在本机 CPU 上预热后中位查询约6秒；仍会漏检。
录制核对发现过摘要工序错配，已补充说明并检查两次重放，保留失败记录。
旧300题的指南成绩依赖历史解析快照；当前版本使用独立的页/区域验证。
